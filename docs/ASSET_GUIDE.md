## Visual system

These values reproduce the current prototype's Ghost-inspired visual language. Before final export, compare the result with [ghostgtm.ai](https://ghostgtm.ai/) in case the live brand has changed.

| Role | Value | Use |
| --- | --- | --- |
| Ink | `#10172A` | Dark backgrounds, headlines, primary text |
| Paper | `#F6F7F1` | Main light background |
| Violet | `#8059FF` | Selected state, active data path, focused emphasis |
| Action violet | `#6238D1` | High-contrast calls to action |
| Pale violet | `#F0ECFF` | Learned-rule comparison and supporting highlight |
| White | `#FFFFFF` | Content surfaces |
| Soft ink | `#4A5265` | Secondary copy |
| Muted | `#667085` | Captions and metadata |
| Rule | `#D4D5D0` | Dividers and diagram connectors |
| Verified green | `#197A4B` | Verified evidence only |
| Warning | `#9A5B0A` | Caution or pending state |

## Typography

The web concept uses `PP Neue Montreal` when available, with `Helvetica Neue` as fallback. For a portable presentation, use this order:

1. PP Neue Montreal, if Genspark can legally retrieve it from Ghost's public site.
2. Neue Haas Grotesk.
3. Helvetica Neue.
4. Inter.
5. Aptos.

Use large compact headlines, sentence case, precise alignment, and generous whitespace. Avoid condensed display fonts, serif decoration, gradients, rounded consumer-SaaS cards, and generic AI imagery.

## Asset use

- Preserve the wordmark's proportions and transparent background.
- Use the workflow screenshot for the experience, evidence, or walkthrough slides.
- Use the Control Tower screenshot for evaluation, learning, and measurement slides.
- Crop screenshots to the relevant interface rather than shrinking a full page until its text becomes unreadable.
- Do not recolor the screenshots or wordmark.
- Label the work `Independent product concept by Ankit Mishra` so the deck never implies official Ghost ownership.
- All Northstar Analytics and Juniper Health content is fictional demo data.
- Dashboard numbers come from a simulated interview dataset, not Ghost customers.

## Source hierarchy

1. The supplied AI Builder Brief controls strategy and assessment intent.
2. Ghost's live website controls current brand and product positioning.
3. The working product and repository control what the prototype actually does.
4. Any proposed CRM, email, authentication, or tenant integration must be labelled as production work, not a current capability.
